# commaKit Development Skill

Follow this workflow for commaKit work:

1. Run `git status --short --branch`.
2. Read root `AGENTS.md`.
3. Read the nearest directory `AGENTS.md` for every path you touch.
4. Use [dev/knowledge/index.md](../../../dev/knowledge/index.md) for progressive disclosure.
5. For R source work, read [dev/knowledge/architecture.md](../../../dev/knowledge/architecture.md).
6. For agent/docs reorganization, read [dev/knowledge/agent-harness.md](../../../dev/knowledge/agent-harness.md) and [dev/knowledge/okf-guidelines.md](../../../dev/knowledge/okf-guidelines.md).
7. Run targeted validation and report exact commands/results.

Do not duplicate durable facts in this skill. Put durable project knowledge in `dev/knowledge/` and route to it from here.
