# Current Priorities

commaKit should remain a small, understandable package for comparative
microbial methylomics. Work should be driven by real analyses rather than by a
fixed maturity framework.

Current priorities are:

1. Verify statistical behavior with realistic biological data.
2. Make the modkit import path clear, strict, and actionable when input is
   malformed.
3. Keep the `commaData` API discoverable for scientists who do not know S4 or
   Bioconductor internals.
4. Test performance and memory use on full bacterial methylomes.
5. Remove abstractions and infrastructure that do not support package users or
   scientific correctness.

GitHub Issues hold specific accepted work. Completed work is recorded by Git
history and `NEWS.md` rather than duplicated here.
