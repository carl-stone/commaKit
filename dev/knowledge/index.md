# commaKit Knowledge Bundle

This directory is the repo's agent-readable knowledge bundle. It follows the Open Knowledge Format v0.1 shape: ordinary markdown files, YAML frontmatter on concept documents, normal markdown links between concepts, and this `index.md` for progressive disclosure.

## Agent Orientation

* [Agent Harness](agent-harness.md) - operating loop for Codex, Claude Code, and similar coding agents.
* [OKF Guidelines](okf-guidelines.md) - local rules for maintaining this knowledge bundle.
* [Project Status](project-status.md) - current package identity, exported surface, source/test inventory, and known current-state notes.

## Package Knowledge

* [Architecture](architecture.md) - current `commaData`, assay, result, parser, annotation, and differential methylation contracts.
* [Design Decisions](design-decisions.md) - architectural decision records and "do not change without" notes.
* [Known Issues](known-issues.md) - bugs, gotchas, edge cases, and resolved/currentness notes.
* [Test Quality Audit](test-quality.md) - historical audit of tests and remaining testing themes.

## Workflow Knowledge

* [Git Discipline](git-discipline.md) - commit, staging, review, and validation expectations.
* [Branching and Releases](branching-releases.md) - branch, PR, version, release, and tag policy.
* [Update Log](log.md) - chronological changes to this knowledge bundle.
