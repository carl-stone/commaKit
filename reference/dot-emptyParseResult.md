# Empty parser result (zero-row data frame with shared parse schema)

Empty parser result (zero-row data frame with shared parse schema)

## Usage

``` r
.emptyParseResult()
```

## Value

A zero-row `data.frame` with columns `chrom`, `position`, `strand`,
`mod_type`, `motif`, `beta`, `coverage`, `mod_counts`,
`canonical_counts`, and `other_mod_counts`.
